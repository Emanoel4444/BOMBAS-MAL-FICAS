# 🧬 Anabolizantes — Conheça os Riscos

## 📌 Sobre o projeto

Este projeto é um site informativo e educativo sobre os **riscos e possíveis consequências do uso indevido de esteroides anabolizantes**.

O objetivo é apresentar informações de forma simples, visual e acessível, ajudando na conscientização sobre os possíveis impactos dessas substâncias na saúde.

> ⚠️ **Aviso:** este site possui finalidade exclusivamente educativa e não substitui orientação de profissionais de saúde.

---

## 🎯 Objetivos

- Informar sobre o que são os esteroides anabolizantes.
- Apresentar possíveis riscos associados ao uso indevido.
- Explicar possíveis efeitos no organismo.
- Abordar diferenças entre possíveis efeitos em homens e mulheres.
- Destacar os riscos durante a adolescência.
- Combater informações falsas por meio de uma seção de mitos e verdades.
- Disponibilizar fontes confiáveis para pesquisa.

---

## 📚 Conteúdo do site

O site possui as seguintes seções:

### 🏠 Início
Apresentação do projeto e uma mensagem de conscientização.

### 🧬 O que são?
Explicação sobre esteroides anabolizantes e suas características.

### ⚠️ Riscos
Informações sobre possíveis consequências relacionadas a:

- ❤️ Sistema cardiovascular
- 🫀 Fígado
- 🧠 Saúde mental
- ⚙️ Sistema hormonal
- 🧴 Pele e cabelos
- 🩺 Rins

### 👨 Possíveis efeitos em homens
Apresentação de possíveis alterações relacionadas ao uso indevido.

### 👩 Possíveis efeitos em mulheres
Apresentação de possíveis alterações que podem ocorrer.

### 🧑‍🎓 Adolescência
Informações sobre os riscos do uso de anabolizantes durante uma fase de desenvolvimento do organismo.

### ❓ Mitos e verdades
Seção destinada a esclarecer afirmações comuns sobre anabolizantes.

### 📖 Fontes
Links para instituições e fontes de informação em saúde.

## 🌐 Publicação no GitHub Pages

Para publicar o site:

1. Acesse o repositório no GitHub.
2. Entre em **Settings**.
3. Clique em **Pages**.
4. Em **Build and deployment**, selecione:

   * Branch: `main`
   * Folder: `/ (root)`
5. Clique em **Save**.
6. Aguarde o GitHub Pages publicar o site.

Depois disso, o GitHub disponibilizará um endereço público para o projeto.
